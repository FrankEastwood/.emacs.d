C-h t (open tutorial)

* page
C-v (pagedown)
M-v (pageup)
C-l (current line position)

* move
C-b (move backward)
C-f (move forward)
C-p (move previos line)
C-n (move next line)
M-b (move backward word)
M-f (move forward word)
C-a (move ahead of line)
C-e (move end of line)
M-< (move begin of file)
M-> (move end of file)

* delete
<DEL> (delete previous)
C-d (delete next)

* repeat
C-u 8 oper (repeat oper 8 times)

* kill & yark
C-k (kill the line)
M-k (kill the line from cursor)
C-w (cut/kill the region)
C-y (paste/yark)

* file
C-x C-f (find a file)
C-x C-s (save a file)

* buffer
C-x C-b (list the buffer)
C-x b (switch to buffer)
C-x k (kill buffer)
C-x s (save buffer)

* eXtend Command
C-x Character
M-x Named command
M-x repl s<Return>changed<Return>altered<Return>

* undo
C-/ (undo)
C-x u (undo)

* Major mode
M-x text-mode <Return>

* Searching
C-s  (echo area show isearch)
C-s again & <DEL> (move next or previos)
C-g (terminal the search)
C-r (search earlier text)

* Multiple Windows
C-x 2 (splits into two windows)
C-M-v (scroll the bottom windows)
C-M-S-v (scroll
C-x o (move cursor to other windows)
C-x 0 (close current window)
C-x 1 (close other window but this)


* install packages
M-x list-packages

* exit
C-x C-c
